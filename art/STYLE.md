# 美术风格指南：木刻版画

定于 2026-11-18。样板图是 `art/inbox/lin_chong.jpg`（林冲）。所有人物立绘都以它为参考，新图要和它放在一起比较，不像就重画。

## 视觉规则

| 项目 | 规则 |
|---|---|
| 线条 | 粗壮的黑色刻线轮廓，线宽和样板一致；造型概括、棱角分明 |
| 颜色 | 只用墨黑、朱红、赭黄、靛青四色平涂，加皮肤的浅赭色；不用渐变 |
| 质感 | 轻微的木纹和印刷颗粒，雪花用白色小点 |
| 构图 | 半身像（头顶到腰），四分之三侧身，**脸朝右**；敌人在游戏里水平翻转 |
| 背景 | 纯白，便于抠图 |
| 比例 | 3:4，出图约 864×1152 |
| 辨识 | 每人一个主色和一件标志物（林冲：靛青斗篷 + 枪挑葫芦），72px 头像也要认得出 |
| 禁止 | 文字、题款、印章、签名、水印、边框、多个人物、裁切到头部或兵器、照搬影视剧造型 |

## 提示词固定段

人物描述写在 `art/prompts/<id>.txt`，`tools/gen_portrait.sh <id>` 会把下面这段拼在后面。

<!-- prompt:begin -->
画风：中国传统木刻版画风格，带一点年画的配色。粗壮有力的黑色刻线轮廓，造型概括、棱角分明，只用 4 种颜色平涂（墨黑、朱红、赭黄、靛青），皮肤用浅赭色，带轻微的木纹和印刷颗粒质感，没有渐变。线条粗细、配色、颗粒质感、头身比例都要和参考图保持一致，但人物要画成描述里的这个人，不要画成参考图里的人。
构图：游戏角色立绘，半身像，四分之三侧身，脸朝向画面右侧，从头顶到腰部，人物居中，四周留白。
背景：纯白色纯色背景，无任何场景。
画面比例 3:4。
不要出现：文字、题款、印章、签名、水印、边框、多个人物、裁切到头部或兵器。
<!-- prompt:end -->

## 处理流程

1. `tools/gen_portrait.sh <id>`：用 Cursor 出图，原图存到 `art/inbox/<id>.png|jpg`（这个文件夹 Godot 不导入）。
2. 和样板放在一起看，不合格就改 `art/prompts/<id>.txt` 重出。
3. `tools/art_pipeline.py`：抠白底，输出 `art/portraits/<id>.png`（立绘）、`art/busts/<id>.png`（卡片半身）、`art/faces/<id>.png`（头像）。
4. 在 `art/manifest.json` 记录来源（AI 生成，工具和日期），上架时回答商店的 AI 内容问卷要用。

# 像素场景风格（俯视场景）

定于 2026-11-19。立绘仍用上面的木刻版画；可以走动的俯视场景用像素风，色调向版画靠拢。

| 项目 | 规则 |
|---|---|
| 视角 | 斜俯视（从斜上方往下看），建筑能看到屋顶和正面 |
| 像素 | 清晰的方块像素，不要抗锯齿和模糊；轮廓用深墨色描边 |
| 网格 | 地面瓦片 16×16 像素，游戏里放大 3 倍（一格 48 像素）；人物约 48 像素高、放大 2 倍，加 1 像素深墨色描边（tools/pixel_pipeline.py --sharp --outline） |
| 颜色 | 暖色调；主色取版画的朱红、赭黄、靛青，加草绿、土黄、灰石色，每张图不超过 32 色 |
| 人物 | Q 版比例（约 2.5 个头高），全身站立，脸朝右；走路由程序做起伏和翻转 |
| 禁止 | 文字、标志、水印、边框、透视错乱、照搬现有游戏的素材 |
